# Macro Tool UI Design

## 目的

Macro Toolは、画面内に指定画像が現れたことを検知し、対応する操作を実行する画像認識マクロツールである。

v0.1では実装速度よりも、画面構成・操作フロー・マクロ定義の分かりやすさを優先する。

## 基本方針

- 座標固定・delay・単純ループを中心にしたマクロ方式は採用しない。
- 「指定画像が探索範囲内に現れたら動作する」イベント駆動型のルールとして扱う。
- 探索範囲は必須とし、誤検知防止と処理負荷の軽減に使う。
- 同一ルールの連続発火防止にはdelayではなくcooldownを使う。
- GitHub公開を前提に、UI・設計・ドキュメントの読みやすさを重視する。

## v0.1の対象範囲

v0.1では以下を設計対象とする。

- メイン画面
- ルール編集画面
- 範囲選択画面
- ルール定義JSON
- 基本的な実行フロー

以下はv0.1では対象外、または後続バージョンで検討する。

- 複数アクションの連続実行
- 条件分岐
- キーボード入力
- OCR
- スケジュール実行
- プラグイン機構
- クラウド同期

## メイン画面

メイン画面は、実行状態の確認とルール管理を行う中心画面とする。

### 主な要素

- 実行開始ボタン
- 停止ボタン
- テスト検知ボタン
- ルール一覧
- ログ表示

### レイアウト案

```text
+--------------------------------------------------+
| Macro Tool                         [Start] [Stop] |
+----------------------+---------------------------+
| Rule List            | Rule Summary / Actions    |
|                      |                           |
| [x] Rule A           | Selected: Rule A          |
| [ ] Rule B           | Image: start.png          |
| [x] Rule C           | Region: 100,200 300x120   |
|                      | Confidence: 0.85          |
| [+ Add] [Edit] [Del] | Cooldown: 1.5s            |
+----------------------+---------------------------+
| Log                                              |
| 12:00:01 started                                |
| 12:00:03 Rule A matched                         |
+--------------------------------------------------+
```

### ルール一覧

ルール一覧では、各ルールの有効/無効と概要を確認できるようにする。

表示項目の候補:

- enabled
- name
- image filename
- confidence
- cooldown

## ルール編集画面

ルール編集画面では、1つのルールを作成・編集する。

### 入力項目

- ルール名
- 検知画像
- 探索範囲
- confidence
- action
- cooldown

### 操作

- 保存
- 削除
- キャンセル
- 画像選択
- 範囲選択
- テスト検知

### バリデーション方針

- nameは必須。
- imageは必須。
- regionは必須。
- confidenceは0.0から1.0の範囲。
- cooldownは0以上の数値。
- action.typeはv0.1ではclickのみ対応する。

## 範囲選択画面

範囲選択画面では、現在の画面をキャプチャし、ドラッグ操作で探索範囲を指定する。

### 想定フロー

1. ルール編集画面で「範囲選択」を押す。
2. 画面全体のスクリーンショットを取得する。
3. スクリーンショットを全画面または専用ウィンドウに表示する。
4. ユーザーがドラッグで矩形を指定する。
5. 選択した矩形をregionとしてルール編集画面へ反映する。

### 表示要素

- スクリーンショット
- 選択中の矩形
- 選択範囲の座標とサイズ
- 確定
- キャンセル

## 実行フロー

```text
Start
  |
  v
Load enabled rules
  |
  v
Capture screen
  |
  v
For each rule:
  - skip if cooldown active
  - crop screen by region
  - match template image
  - execute action when confidence threshold is met
  - update last_triggered_at
  |
  v
Repeat until stopped
```

## UI品質の方針

- 操作対象が明確な、静かで実用的なUIにする。
- 実行中か停止中かを一目で分かるようにする。
- エラーはログだけでなく、必要に応じて画面上でも分かるようにする。
- ルール編集では、未入力・不正値が保存前に分かるようにする。
- ポートフォリオとして見たときに、設計意図が伝わる構成にする。
